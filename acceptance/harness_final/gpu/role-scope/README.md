## 原簽紀錄可支持哪個判讀

1. 事件 108 的第二份命題已引用特定的預測、參照晶體與位置圖，各有內容固定的 artifact。事件 114 採納時，方法釘住 reference 角色、具名 `calpha_rmsd_A`、ångström 單位和 `≤2` 門檻。同筆決定的唯一 scorer 節點在 119 指定三份輸入及次序。123 建立正式 Job，128 才發布分數。這條鏈支持對該三元組的事前 RMSD 假設作否定性判斷。[固定測量的首次發布](score-publication.json)
2. 122/123 足以通過保管者與 Lead 分別預先寫下的 90% 覆蓋條件。GX 原 prediction 的正式機讀規格只含一個 RMSD 比較式。覆蓋條件存在於人可讀的 criteria，明示的 primary data 只含晶體。已發布報告的第二條自動裁決應維持 `registered_without_qualifying_result`。首次與第二次登記合計 **0/2**。
3. 現行 `v622_measurement.match` 要求科學適用範圍集合只有該命題的字串，且只在測量具有單一來源時輸出 material_inputs。此處的實驗晶體和位置圖各有自己的用途說明。即使改用指定 reference 的適用文字及角色，現行 `v62_maturity` 還會要求產物來源都是已取得的原件。這筆比較包含被評估的新模型；若把模型標成實驗原件，證據種類將失真。此次工作保留原產品裁決，將可證的三元組子結論獨立記錄。
