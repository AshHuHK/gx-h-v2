**科學結果。** BRENDA 的 `3.2.1.10/specific_activity/59` 與 Deng 等人（2014）Table 2 的 Ima3p 欄指向同一筆彙總結果。5 mM α-pNPG、pH 7、30 °C 下，平均比活性為 3.9 μmol/min/mg。括號裡的 54 是相對於同一酶的異麥芽糖反應速度的百分比。該表彙總五次實驗；工作表不能據此增列一筆獨立結果或補寫五個重複測量值。菌株欄應區分論文討論的 S288c 基因組與實驗報告的 CEN.PK113-5D 表達宿主。三份實際報告均保留原文。[原生報告](study-1/report.md) · [基線報告](study-2/report.md) · [重構版報告](study-3/report.md)

**執行差異。** 基線在 SQLite 事件 22 路由 E2、事件 56 結題，期間有一次 `close_run` 提交。重構版在事件 27 路由、事件 110 結題，並完成一個委派模組。其 11 次 `close_run` 提交與全案 14 筆結構拒收是兩種不同的計數。拒收欄位包含決策結構、操作、結題理由與 PI 意見處置。兩個 GX 場臂的關鍵材料提醒均為零；原生 Codex 沒有這個 GX 操作。這份對照保留新版的實際成本與負面結果。[事件逐條紀錄](engineering.json) · [逐筆 close 提交與讀數](results.json)
