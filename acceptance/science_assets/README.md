# GX 可復用科研資產與現場驗收

研究者可以用一個問題開題。需要在不同材料上保持相同的驗收口徑時，可以給任務卡；具體用哪個方法、何時委派、讀到證據後是否改變判斷，仍由 Lead 決定。GX 用同一個目錄展示可執行方法、可用的配方和歷史參考。Job 的具名輸出、來源 Run、提供者版本與材料摘要保存在各題的記錄中。[四種卡的設計、註冊與命令](CARDS.md) · [上機部署及恢復](deployment/README.md)

## 科學與工程邊界

新序列生成與重設計、酶的改造及活性優化、Fab 的親和力設計與新構象預測，本次均無執行簽收。既有權重或舊工作流的位置只證明可以找到該資產。天然酵母的歷史註釋、已發表結構的坐標及檔案覆蓋不能直接回答上述設計問題。RNA 本輪只有索引。

Lead 可保留證據不夠的結論。相同位元的原始附件與研究產物各自保留來源。單步查詢配方、成功的整個質控流程、多 Job 但沒有資料依賴的並列分析，各自按真實圖和新題引用簽收。更換材料或主動要求獨立複算有自己的 Job；冷恢復先接回原 Job。[來源與後繼](CARDS.md) · [恢復、引用與重算](reuse/README.md)

最值得接著遷移的是帶有逐條底物、測定條件、單一蛋白歸屬與原論文定位的已發表酵母測定資料。這批實跑已經具體指出，較寬的 EC 分類無法補上這些欄位。加入這類既有實驗來源後，可直接用同一對天然酵母題測試有多少未知能被解除。
