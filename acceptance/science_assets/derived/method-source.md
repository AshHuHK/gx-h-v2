# Bibliographic locator coverage, revision 1

The cohort consists of the distinct source-qualified Europe PMC record IDs returned in one saved search response.
Match each source-qualified record ID to a nonempty PMCID in the archived provider metadata.
Use the original source and record ID together, preserve case, count each record once, and retain records without a PMCID in the denominator.
A recorded PMCID supplies a locator for a separate full-text acquisition. A missing PMCID does not establish that no full text exists.
