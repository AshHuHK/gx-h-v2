# Deposited molecular records field study

Each question is an archive quality-control exercise. The unit of replication is a deposition. NMR conformers, duplicate representations, the raw coordinate file and a derived numbering map can share a scientific source. The reference values for the chosen public controls were already available to maintainers. The questions supplied to the Lead omit these values and method names.

A successful measurement must link the ordinary Goal to a new CPU Job, its actual inputs and the named JSON output. A decision must trace to the evidence that the Lead received. Count a saved or instantiated workflow from the accepted native operation. For a later independent Fab case, examine both the changed coordinate file and changed mapping as well as the freshly produced measurement. Unadopted recipe proposals and manual/controlled operations are labeled separately.

| Material | What is compared | Independent check |
|---|---|---|
| 6BEN and its supplied derivative | Recorded intrachain terminal connection versus model-wise end geometry and coverage. The derived file removes one declaration only. | Check the mmCIF edit byte-for-byte; recompute distances from the separate legacy PDB with 1e-6 Å absolute tolerance. All integer counts must match exactly. |
| 1UAO and 1LE0 | Label-chain polymer positions versus annotated amino acids, positive-occupancy observed sites and compatible complete backbones. End groups and unknown annotations stay in their proper denominators. | Compare every NMR model against the independently parsed PDB fixed-column records. Integer counts must match exactly. |
| 4FAB then 1MCP | Numbered IMGT CDR coordinates in the supplied assembly, heavy and light chain separately, including insertion labels and absent positions. | Compare named IMGT intervals against independent coordinate reads. Integer counts must match exactly. Reject mismatched source/role and missing chain. |

Peptide conformational confidence, experimental efficacy, binding and engineering yield are outside these archive measurements.
