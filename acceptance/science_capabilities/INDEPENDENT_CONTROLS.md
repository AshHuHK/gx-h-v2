# 三个正式 Run 的独立复核

三个研究均从真实 CPU Job 获得读数，Lead 在收到读数后结题。独立复算与 Job 读数一致。证据文件保存了每个 Run 的 Job、原件哈希、读取回执、结题决定、预测原判及首版简报的文本摘要值。[逐例回执](evidence/independent-controls.json)

| 研究 | 独立复算及科学结论 | 生效事件 |
| --- | --- | --- |
| Top7 | 独立读取 1QYS 的 PDB 文本。声明 106 位，3–94 共 92 位具有完整骨架。用两两距离复算 Cα 回转半径得 12.2160622315 Å，绝对差小于 2×10⁻¹⁴ Å。此数值只描述有坐标的区段。 | 68 → 69 |
| 6BEN | 从 PDB 文本复算 20 个模型，末端 C–N 距离在 1.328375–1.341118 Å 内。人工删除唯一头尾连接记录 covale2 后，20 组距离逐一保持相同。Lead 用原始 mmCIF 自行比对获得同一结果。距离可支持几何相容性，仍需另核存档的连接声明。 | 108 → 109 |
| BglB | 从两份原始 DOCX 独立取数、重新按位点分组并计算并列秩。留出 41 项，30 项有定量效率，14 项有配对评分，ρ = 0.259626；同组 WT 常数预测的中位绝对 log₁₀ 误差为 0.388205。此结果限于已发表、可配对的 14 项。原始登记仅覆盖 S1，双来源研究保留正式判定“未定”。 | 79 → 81 |

三个首版 Markdown 简报均省略了影响解读的细节。Top7 简报给出 92/106，完整决定还列出区段和半径。6BEN 简报显示模型 1 距离，完整决定还指出删去 covale2 后逐模型距离仍相等。BglB 简报显示 ρ，完整决定还列出三级分母和 WT 基线误差。机读凭证记录了各数值是否出现在本次复核的简报中，并给出该版本的哈希。

从发布目录可在已有本地 Run 状态上复验。命令只读研究状态，输出至指定文件。复算和人工文本核对均未调用模型。

```sh
PYTHONPATH=. .venv/bin/python -m acceptance.science_capabilities.independent_controls \
  ../gx-science/capabilities-check /tmp/independent-controls.json
```
