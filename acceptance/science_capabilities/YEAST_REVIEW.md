## 海藻糖

Run `gxr_01m8d9q2sexhdhq33k` 取得 S288C 背景遗传研究 PMC11540316。Methods 第 p18 段说明实验用了 S288C 衍生株。p26 说明研究者先提取细胞碳水化合物，再用外加商品海藻糖酶释放葡萄糖。p55–p56 与图 7 比较了营养恢复期间不同基因型细胞的海藻糖储量变化。这些数据支持中性海藻糖酶参与细胞内海藻糖动员。它们不能给出各个天然酶的独立催化速率。p50 同样说明，以胞外海藻糖为碳源的生长表型仍允许不同的水解位置。[原论文](https://doi.org/10.1093/g3journal/jkae215)

PMC7124472 则提供纯化蛋白读数。p125 与图 9（p194–p195）记录重组酵母 Nth1 的海藻糖反应，观察到葡萄糖随时间生成，支持 Nth1 在受试条件下直接水解海藻糖。该制剂的来源不能据此外推为天然 S288C 纯化酶。Nth2 旧文 PMID 7730323 的作者摘要已由真实研究者解码并从工具返回。逐字核对确认 PMID 8346677、8764988、18065618、15128531 的完整摘要也实际送达。PMID 24951963 仅核到摘要的部分显示。这些文章均没有本题全文段落回执。其结论仍须与已核的原文及评论区分。[Nth1 原始测量](https://doi.org/10.1074/mcp.RA120.001955)

本地反应索引命中 NTH1、NTH2 和 ATH1 对应的三个 accession。三份 UniProt 原件成功取得。其中 P35172 的名称为 Probable trehalase，GO:0004555 的证据代码为 IMP:SGD（突变表型）。P32356 与 P48016 的对应 GO 项标注 IDA:UniProtKB（直接测定）。代码记录的是数据库对原始证据的归类。核查 p26、p35.1 及相关异议后，Lead 按旧基因名 YBR0106 追加原始研究检索，Job `gxj_01m8dah3setqj2vnxy` 执行成功。相同来源的多次数据库读取保留同一证据权重。两项不同 Job 还成功获取了相同 SHA-256 的 PMC3953731，该文只计一次。独立核对原件表 2（t0010）的列标题和两条底物行，四种天然异麦芽糖酶 Ima1p/2p/3p/5p 对海藻糖报告值均为 0，同一制剂对异麦芽糖分别为 60、54、7.2、65 μmol/min/mg。这个阴性结果只适用于所测制剂和条件。PI 定向反馈事件 201 要求核对底物、材料和直接测量。受派文献模块已读 p26 并提取了原文定位。Main 对同一消息的正式答复于 01:57:41 UTC 入账，指出图 2a 测的是缺失株细胞提取物中的海藻糖池，定量水解来自外加检测酶，要归因到单一蛋白仍需直接底物测定。该答复与不可变原件 p26 和 p35.1 相符。本题文献模块交付 7 项有来源的 findings。另三份 GX 自动生成的 PARTIAL 报告均有 0 项 findings。后续两次来源复核（事件 2549、2552）为新命题版本引用同一旧原文提供了回执，原实验数量维持不变。

另行取得的 PMC3531729 提供另一种实验层级。p88 在**细胞粗提液**中测酶活，以释放的葡萄糖定量；图 2A 的 p101 记载补糖后活性上升。p99 用纯化重组蛋白做的是磷酸化位点分析。把这两种制剂拼接，会把粗提液活性错误归给单一纯化天然酶。[原文与图](https://europepmc.org/articles/PMC3531729)

海藻糖 Lead 在 e2616 提交结题决定，e2617 生效。决定实际引用了唯一的作者报告 `gxa_ef26ddde4caa659ec5d07aab5fef939c83b2d7be7bf3755320adf9f545b587b9`。Lead 区分了 Kienle 的酸性酶制剂释糖、无酶空白（PMID 8346677）与 Alizadeh 和 Klionsky 的纯化蛋白身份鉴定（PMID 8764988）；两篇均只核到了作者摘要。关于 Nth2，旧摘要报告破坏 YBR0106 后酶活及储糖未见改变，较新的摘要报告 NTH2 对储糖动员有功能。两次实验的菌株、条件、对其他酶贡献的控制仍待查原图，不能据此认定 S288C 纯化 Nth2 直接水解底物。GX 封存 9 项命题，S288C Nth2 的直接催化证据为 `insufficient`，另 8 项为 `open`，均为 `idea/undetermined`。

## 蔗糖

Run `gxr_01m8d9xyhw3b1ftg09` 的 Lead 读取 PMC11462787 的 p19 和 p65。原文列出商品来源的酿酒酵母转化酶，在体外加入蔗糖，跟踪信号随时间变化，并用单糖标准品比对。该制剂的底物转化有直接读数，原文未给出可确认的 S288C 供体。PMC3153487 的 p66 提供 S288C 背景的生长表型，p20 指明主实验用了 W303。两份实验的材料和终点不同，无法据此宣称已测得 S288C 纯化 Suc2 的催化常数。[制剂研究](https://doi.org/10.1177/00037028241258109)

另有更强的菌株级材料。PMC5021340 表 1 将野生型 S288c 对应到 ATCC 204508，p81、p82 记录洗涤完整细胞与蔗糖的反应及 DNS 释糖读数。复核表 4 的 S288c 列可见，单用半乳糖培养和同时用半乳糖、葡萄糖培养，读数分别为 3.3 ± 0.5 和 0.5 ± 0.1 g 葡萄糖当量/g 干酵母，来自三份独立培养。该比较支持特定培养条件下完整 S288c 细胞对蔗糖的水解能力。DNS 不能单独区分葡萄糖和果糖，完整细胞测定也无法归因于某一纯化蛋白。[菌株级原始测量](https://doi.org/10.1371/journal.pone.0162838)

### 仅凭结果汇总定位两篇原件

`evidence/yeast-review.json` 的 `trehalose.offline_locator` 指向 PMC7124472 图 9 图注 p195，`sucrose.offline_locator` 指向 PMC5021340 的 DNS 测定段 p82。两条均带 Run 所属节、原始 Job/Artifact、欧洲 PMC 原件 URL、内容版本、全文 SHA-256、准确的 XML 元素路径和段落 SHA-256。原件来源分别是 [PMC7124472 JATS](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7124472/fullTextXML) 和 [PMC5021340 JATS](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5021340/fullTextXML)。

将这两份**原始 XML 字节**分别保存为 `PMC7124472.xml` 和 `PMC5021340.xml`。下列命令只需 Python、公开汇总及这两份 XML 即能逐段复核。验收中，两份原始 XML 均通过，对其中一份只追加一个换行便触发版本不符。若公开站点后来修订文章，程序会指出原件哈希不符，此时可用汇总列出的原 Artifact 获取研究当时的字节。

```bash
.venv/bin/python -B acceptance/science_capabilities/verify_yeast.py \
  --check-originals acceptance/science_capabilities/evidence/yeast-review.json \
  --article-dir /path/to/two-xml-files
```
