# 2RE9 与 2O0O 的独立数值复核

两份沉积都可以逐对检查 AB、AC、BC，再报告三对的中位数。2RE9 的 A–C 在 101–120 区段提供了需要单列的例子。删去该区段后，完整骨架的 A–C 拟合旋角由 120.229464° 增至 120.842187°，三对中位数却从 120.229464° 降至 119.799650°。A–C 变化 0.612723°，超过产品固定的 0.50° 限值，中位变化 0.429814°。仅取 Cα 时也出现相反方向，变化分别为 0.594142° 和 0.410604°。这项固定限值检查由 Lead 查阅结果后追加。

### 读数前选定的筛查

每个合格区段分别检查旋角和 RMSD。链对变化须至少达到 0.05° 或 0.01 Å，达到同一区段三对中位变化的两倍，并严格超过该链对 20 组等量分散删点对照的最大变化。下表各单元依次给出链对变化、中位变化和对照最大值。区段采用各沉积自身的标签编号。

| 沉积、区段和链对 | 指标 | 完整骨架 | Cα | 达到全部条件 |
|---|---|---|---|---|
| 2RE9，21–40，A–C | RMSD（Å） | 0.252804 / 0.126120 / 0.101710 | 0.224322 / 0.125156 / 0.077692 | 完整骨架 |
| 2RE9，41–60，A–C | RMSD（Å） | 0.120552 / 0.024954 / 0.112872 | 0.170055 / 0.031370 / 0.091164 | 两种选择 |
| 2O0O，21–40，A–B | 旋角（°） | 0.391912 / 0.067890 / 0.147052 | 0.355647 / 0.013998 / 0.100626 | 两种选择 |
| 2O0O，21–40，B–C | 旋角（°） | 0.329361 / 0.067890 / 0.244652 | 0.357730 / 0.013998 / 0.221405 | 两种选择 |

2RE9 的 21–40 A–C 完整骨架 RMSD 变化仅比两倍中位变化高 0.000563 Å，仅取 Cα 后低于该界限。另外三项只在 Cα 下达到全部条件，包括 2RE9 的 41–60 A–B RMSD、81–100 B–C 旋角和 2O0O 的 81–100 A–B RMSD。2O0O 的 21–40 B–C RMSD 在完整骨架下降 0.329986 Å，三对中位数下降 0.212740 Å，均超过产品固定的 0.15 Å 限值。两种原子选择的全部 192 个合格链对、区段和指标组合均有未舍入值。本轮四份结果表的 SHA-256 与仓库已有公开表对应的产物摘要逐一相同。[逐项测量](../../../../v623/evidence/study/tables/pair_intervals.csv)

### 坐标与复算

分析使用 2RE9 rev 1.4 与 2O0O rev 1.3 的模型 1、实体 1、不对称单元标签链 A/B/C。按三链共有的标签位置、残基名及原子名匹配，分别选等权 N、Cα、C、O 四原子的完整骨架，或每个位置的单个 Cα。2RE9 有 164/164 个匹配位置，2O0O 有 152/153 个。20 个标签位置构成一个区段，每份沉积均有 8 个合格区段。20 个分散对照从目标区段外至少三个不同区段删除相同数目的匹配位置。三对中位变化取删段前后三对链各自中位数之差的绝对值。两份沉积共用一篇论文，生物取样的独立性未知。

原 Run 的四份全表使用 Horn 四元数拟合。独立计算使用 Bio.PDB.MMCIF2Dict 1.88 重新读取原始 mmCIF，以 NumPy 1.26.4 的 SVD 求正旋转。逐项比较全表和对照时，角度变化的最大绝对差小于 3.56×10⁻¹³°，RMSD 变化的最大绝对差小于 3.45×10⁻¹⁵ Å。单次拟合的复现容差为 0.01° 或 0.001 Å，变化量容差为 0.02° 或 0.002 Å。六份单格产物与源表一致，结题引用的 52 项指标在显示精度内全部一致。逐项引用保留了对应 Job、原子选择、原显示值与独立复算值。验证记录列出原坐标文件、版本、SHA-256、各表和单格 Job 的输出摘要，以及显示精度与数值误差。[结题引用的 52 个读数](closing_readings.csv) · [验证记录](verification.json)
