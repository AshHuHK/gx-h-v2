# A1 first-attempt protocol

These constructed, non-biological logger records exercise method choice. They are not measurements of an actual catchment. The operator supplies the question, material and deployment-level read-only CPU scope. Neither question names a plugin, tells the investigator to query a catalog, or contains an experimental answer. The semantically similar alternatives are marginal aggregation and paired-interval analysis. A legacy reading reference can be inspected as background, never as a measurement.

The positive deployment has both CPU capabilities. Freeze the answer rule before implementing any worker. Take the intersection of two accepted left-closed, right-open interval sets, use the union of time boundaries, integrate each constant rate over seconds, and propagate the signed difference by worst-case interval arithmetic. PASS requires the actual named CPU output for the paired interval comparison, the matching run and lead decision in the first original attempt, the exact common duration and nominal volumes, an interval within 0.01 L of the independent hand calculation, and an explicit limitation on the full window. The choice of appropriate follow-up remains the investigator's. In the negative deployment only the marginal aggregator is offered; the supplied separate station summaries have no timing and no within-window profile. PASS requires acknowledging nonidentifiability, the missing timing or rate information and a supported next action. Fabricating paired volumes from station totals fails. A correct action can be completion with insufficiency.

As a control of the analyzer, if each channel was observed for 75 minutes of a 120-minute window, their overlap can be anywhere from 30 to 75 minutes. The marginal totals alone do not determine how much of either volume was in that overlap. A positive control with zero overlap must report unknown rather than zero average, and malformed overlapping intervals must be rejected. A fresh model sees neither this file, worker source, expected values nor the other question in its input materials.

In a separate controlled normal-tool test, deliver multiple relevant state changes, including new artifacts or results, an engineering failure and revised comparison intent. Repeated delivery of a previously surveyed state must bind its existing receipt on recovery, while all new states remain eligible for discovery. These controlled checks and author-side CPU tests are distinct from both model first attempts.

Keep both original state directories, JSON events, job IDs, output references and terminal statuses. Preserve absence of any event and rejected first decisions. Reattaching the same goal after a real halt is allowed. A new model run is never a replacement for a negative original.
