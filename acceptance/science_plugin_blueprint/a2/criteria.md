# A2 盲題的預先判準

首案固定為 `skyglow-a2-first`。單層自讀或委派由 Lead 選擇；完整的署名交接及獨立複核另行計分。起始材料採 Falchi 等 (2016) 圖集的 NCBI JATS 及同 DOI 的 Crossref 出版索引。第一次原文段落閱讀落庫後，透過一般 PI 訊息向同一 Run 交付 Kyba 等 (2017) 對地面人造燈光輻射的研究。首案保留所有嘗試。

- 核對實讀段落及摘要與方法區別。原作者估算的天頂亮度與直接測得的全夜星星可見度屬於不同端點。世界圖集含特定氣象、大氣、時間、光譜及空間假設，現地街區及換燈前後結論應有可定位的適用說明。
- 相同 DOI 的兩個介面只能貢獻一份研究。後到文章能提供時間比較，需辨明衛星觀測量、夜間過境時間及光譜侷限。文章數量不證明統計獨立。
- 留存首批與後續讀取範圍、實際作者與回合、GX 的傳遞記錄、原文出處、Lead 的生效處置。重要爭議若交付複核，應有兩位研究者各自所讀的原文與判詞。若沒有走過委派或獨立複核，分列缺失。
- 沒有同時段現地觀測及合理的對照時，個別街區全夜或因果變化可保留未知。記錄每項做法及是否有根據；題面不預填方法或判詞。
