# A1 — Public Goal, local module and CPU inventory

The same human question, source digests, method grants, parent budget and scripted host are used for two independent Runs. One starts in quick mode and commissions the two Jobs itself. The other starts in medium mode, opens one `data_inventory@1` instance and waits for its round. Each method receives a supported file. The 2RE9-specific quality tool counts positions in 2RE9 only. The deposited-chain method measures the common C-alpha selection in 2O0O. Both implementations are the already pinned scientific providers.

The peer uses only its native request, the current frozen brief and GX tool replies. It contains no reference values from a coordinate inventory. After the study, a separate verifier checks both Jobs' admission and output identities and actual process outcomes, reads the cited artifacts, and independently computes position counts and the second deposition's three fits. Both Runs must terminate and cold reopen with identical scientific records and charges, and the module arm must return its sourced report through a distinct module lease and a single round wake.

From the V6.2A product checkout, use a new evidence directory outside the product and the deployed local Clash executable. The wrapper creates a loopback-only network namespace with a reject-all Clash configuration. The official host uses a clean temporary account with a local Responses peer. The following invocation requires zero paid inference.

```bash
work=$(mktemp -d)
.venv/bin/python -B acceptance/phase2a/regression/loopback.py \
  --clash "$GX_CLASH" --receipt "$work/network.json" -- \
  .venv/bin/python -B acceptance/v62a/official_inventory.py --work "$work/inventory"
```

`inventory/result.json` contains each turn's brief bytes, tools, starting graph head, lease, scripted tokens, ledger confidence, source and report identities, wake events, and the observed computing cost. It gives SHA-256s for the wire requests, CLI responses and SQLite backup in each arm’s private raw directory. A fixture response emits 35 synthetic tokens. The authoritative usage ledger may conservatively book a larger estimate following an incomplete terminal receipt. The measured wire count and GX booking are recorded separately. Neither the supply of paid model tokens nor real-world model benefit is observed in this experiment. CPU seconds and duration are single-run measurements.
