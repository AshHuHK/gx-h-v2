# Public coverage pilot scoring

The public protocol has one independent Run per assigned cell. A Run contributes at most one science judgment and, when delegation is available, one delegation observation. The paired private preregistration retains its original baseline, score, and denominator.

The first-stage reader receives the initial accepted plan and observations through the first actual delivery of a qualifying measurement. The reader packet omits the intervention key, assignment, later decisions, costs, report references and arm. The measured endpoint or the scientific wording can still reveal the condition. The lock binds the packet, Run, assay, assignment, report and metric receipts.

The scorer verifies the artifact and SHA of the assigned bytes, acquisition, original publication, receiving scope and frozen grant, authorizing native decision, admitted Job, completed named output, declared nature, source pins, rendered counts, denominator and actual delivery to the Run Lead. A module commissioned before assignment needs a later immutable delivery to its scoped task. A module commissioned afterwards must have received the material in its original grant. Offering a module is insufficient for a delegation observation.

The second-stage reader gets the locked first window, original plan, committed decision and checked effects. In this public scripted case a change withdraws the actual provisional comparison. Maintenance cites a passing measurement and completes the same registered comparison on the reference in its original branch. Both require the same scoped count, a formal revision that cites and renders it and a match to the independently computed endpoint. A provisional route explicitly awaiting the measurement may still be withdrawn or maintained. An initial plan that already excludes the challenged scope is recorded separately. Automatic dispatch, text alone, uncited measurements and out-of-scope work earn no science credit. Replaying a later brief cannot replace a missed first opportunity. Any formal unsupported positive publication precludes a science pass.

For the scripted engineering rehearsal two deterministic stages stand in for the independent readers. Slot order and the scripted grammar are public. This tests the scoring path and cannot establish a live-model judgment or a blinded human result. A live series needs separately recorded independent reader and adjudicator judgments, provider receipts and its own prospective funding. This command only accepts a registered loopback rehearsal.

```bash
python -B acceptance/v62c/rate.py --work "$trial" --stage opportunity
python -B acceptance/v62c/rate.py --work "$trial" --stage outcome
```

Running both stages without `--stage` freezes every available first-stage packet before opening the oracle. By default `$trial/scores.json` is the per-cell summary; `$trial/ratings/<slot>/` contains the read-only extraction, reader packets, committed lock, review and outcome. The Run database and original official-host rollout remain the underlying evidence. Costs are labeled by scope, metering source and actor class. Scripted token observations are engineering measurements. Unreported provider prices are JSON null.
