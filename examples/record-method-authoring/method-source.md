# Identifier mapping and evidence coverage

Ahmad et al., “The UniProt website API: facilitating programmatic access to protein knowledge”, Nucleic Acids Research (2025), DOI 10.1093/nar/gkaf394. Section “ID Mapping service”, first paragraph, describes an asynchronous service for mapping identifiers across databases. The authors describe the service as “an asynchronous job API service to map the identifiers of one database to another”. Table 3 distinguishes paginated results from a full download.

For a local evidence-coverage audit, count unique cohort identifiers with a located evidence value. This last sentence is the local analysis specification, independently derived for this question. The paper describes the ID mapping service. It does not propose this estimator. Use the same identifier namespace or a supplied crosswalk. Absence from a partial or paginated snapshot leaves the scientific status unknown.
