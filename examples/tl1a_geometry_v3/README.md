# TL1A coordinate review Jobs

Start `bin/gx-p0 start --state STATE --tl1a-geometry` and continue with `bin/gx-p0 run --state STATE --timeout 300`. The example selects `tl1a_geometry@3` with six total Job submissions across at most two rounds. A full two-round study can use one quality inventory, three distinct measurement Jobs, and two independent batch review Jobs. The planner selects protocols and can stop after the first round. The decision task's available measurement count leaves room for the next independent review.

An assigned evidence reviewer calls `gx_recalculate_geometry` for a measured protocol. GX queues one batch for all routes in the current evidence set. If the receipt says `waiting`, the reviewer calls `gx_wait_job` and ends that turn. After the Job completes, each measured protocol returns its own `check_ref`. Repeated requests use the same Job and the same collection receipts. New Intent, evidence, or a new independent reviewer can commission a different review.

The execution manifest identifies the reviewer task, attempt, lease and thread. Its inputs pin the original mmCIF, frozen criteria and a collection containing the exact bytes and artifact identifiers of the assigned measurements. Each member distinguishes the original Job output from any later authorized rescoring. The detached `tl1a-review@1` capability verifies these bytes, parses 2RE9 with Biopython, fits corresponding atoms using SVD, and publishes `checks.json`. The raw artifact retains the mapping, each pair result, numeric differences and tolerances. Its per-route receipts link the original request and collection calls to the Job and completion manifest. An unreproducible measurement or an unavailable protocol fit is recorded explicitly and qualifies the scientific conclusion.

The source supports geometric comparisons among the modeled chains of a single crystal structure. Historical `tl1a_geometry@1` and `@2` projects retain their original workflow pins and reviewer products.
